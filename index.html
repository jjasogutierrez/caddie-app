Conecta tu robot

Una sola vez. La app necesita una “llave” de GitHub para dar órdenes a tu robot. Se guarda solo en este móvil.

  1. Entra en github.com → tu foto → Settings.
  2. Abajo del todo: Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Nombre: caddie. Expiración: la que quieras.
  4. En Repository access → Only select repositories → elige caddie-golf.
  5. En Permissions → Repository, pon en Read and write: Contents y Actions.
  6. Generate token y copia el código (empieza por github_pat_).
